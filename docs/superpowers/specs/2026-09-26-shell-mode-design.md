# Режим КОНСОЛЬ — голосовой ввод команд шелла

Дата: 2026-09-26

## Цель

Диктовать команды в терминал так же, как текст в режиме ДИКТОВКА, но с
пониманием синтаксиса шелла: имён программ, флагов, спецсимволов и путей.
Команда вставляется в строку терминала и **не выполняется**, пока
пользователь не скажет «ввод».

## Что сказал пользователь

- Говорить можно и буквально («эл эс минус эл тильда слэш загрузки»), и
  намерением («покажи файлы в загрузках»): сначала правила, если не вышло —
  LLM.
- LLM настраивается; начинаем с ollama.
- Фразы: вход — «консоль», выход — «хватит консоль».
- Команда вставляется без Enter.

## Допущения

- Выход также по «конец текста» — как из диктовки, для единообразия.
- Запуск вставленной команды — существующей фразой «ввод» (Enter).
- Модель по умолчанию — `qwen2.5-coder:3b`: видеокарта на 6 ГБ, из них
  ~1,4 ГБ занимает whisper medium; 7B-модель впритык.

## Состояния и фразы

Новое состояние `SHELL = "КОНСОЛЬ"` рядом с `SLEEP`, `COMMAND`, `DICTATION`.

| Откуда | Фраза | Куда / действие |
|---|---|---|
| КОМАНДЫ | «консоль» | КОНСОЛЬ |
| КОНСОЛЬ | «хватит консоль», «конец текста» | допечатать буфер, затем КОМАНДЫ |
| КОНСОЛЬ | «ввод» | допечатать буфер (с обрезкой хвоста), затем Enter |

Грамматика vosk в КОНСОЛИ: фразы выхода + «ввод» + `[unk]`. Хвост фразы
обрезается так же, как при выходе из диктовки (`trim_s`), обрывки этих слов
чистятся из текста whisper регуляркой, аналогичной `EXIT_TAIL_RE`.

«Ввод» принимается только отдельной фразой (не хвостом за речью, в отличие
от выхода) и с уверенностью vosk ≥ `MIN_CONF`: он жмёт Enter, и «эхо ввод
данных» выполнило бы недоговорённую команду. Минимальная длина фрагмента для
whisper в КОНСОЛИ — 0,5 с вместо 0,8 с: «топ», «сиди» короче.

Смена состояния, сброс буфера, остановка мыши и головы — общие с диктовкой
через `set_state`. Трей: пункт «Консоль» и отдельный значок
(`utilities-terminal-symbolic`).

## Конвейер фразы

Новый модуль `shell.py`, от демона не зависит. Точка входа:

    to_command(raw_text: str, cwd: str, llm: Llm | None) -> str

1. **whisper**: `language="ru"`, `initial_prompt` со словарём шелла
   (слэш, тильда, минус, гит, судо...), чтобы поднять вероятность этих слов.
2. **Правила** (`rules(raw, cwd) -> str`):
   - нормализация: нижний регистр, пунктуация whisper убирается;
   - произносимые символы: «слэш» `/`, «точка» `.`, «тильда» `~`,
     «минус»/«дефис» `-`, «два минуса» `--`, «пайп»/«труба» `|`,
     «звёздочка» `*`, «больше» `>`, «меньше» `<`, «амперсанд» `&`,
     «доллар» `$`, «равно» `=`, «кавычка» `"`. Символы приклеиваются к
     соседним токенам без пробелов (`минус эл` → `-l`, `тильда слэш` → `~/`);
   - буквы по-русски для флагов: «эл» `l`, «эй» `a`, «эр» `r`, «эф» `f`,
     «эн» `n`, «эйч» `h`...;
   - словарь программ: «гит» `git`, «эл эс» `ls`, «сиди» `cd`, «кэт» `cat`,
     «судо» `sudo`, «греп» `grep`, «вим» `vim`, «питон» `python3`,
     «эм кей дир» `mkdir`, «эр эм» `rm`, «эм ви» `mv`, «си пи» `cp`...;
   - **пути**: токен-аргумент (не флаг, не символ) нечётко сопоставляется
     (`difflib`, порог ~0.7) с именами в каталоге, куда указывает уже
     набранный префикс пути (или cwd). Сравнение по исходному слову и по его
     латинской транслитерации; плюс таблица синонимов для XDG-каталогов
     («загрузки» ↔ `Downloads`, «документы» ↔ `Documents`, «рабочий стол» ↔
     `Desktop`...). Нет совпадения — токен остаётся как есть.
3. **Проверка**: первый токен результата — программа в `PATH`
   (`shutil.which`) или встроенная команда (`cd`, `export`, `source`,
   `alias`, `echo`, `pwd`, `exit`, `history`...)? Да — вернуть результат правил.
4. **LLM** (иначе): промпт с сырой фразой, cwd и до 50 имён из него; ответ —
   ровно одна строка команды без пояснений и без markdown-ограждений
   (ограждения/кавычки срезаются). Таймаут 10 с. Ошибка или `backend="none"`
   → возвращается результат правил, в журнал — предупреждение.

Результат вставляется существующим `Paster.paste` (xclip + Ctrl+V; в
терминалах GNOME вставка — Ctrl+Shift+V, см. ниже).

**Вставка в терминал.** Ctrl+V в gnome-terminal/Ptyxis не вставляет. В
режиме КОНСОЛЬ `Paster` жмёт Ctrl+Shift+V (параметр `paste(text, keys=...)`).

## cwd терминала

`terminal_cwd() -> str`: среди `/dev/pts/*`, принадлежащих пользователю,
выбрать с самым свежим mtime (он меняется при вводе/выводе в терминал);
найти в `/proc` процесс оболочки (`bash`, `zsh`, `fish`, `sh`) с этим tty
(поле 7 в `/proc/PID/stat`), предпочитая лидера foreground-группы; вернуть
`readlink /proc/PID/cwd`. Любая ошибка → `$HOME`. Эвристика: если
фокус в другом терминале, чем последний активный, пути будут
сопоставлены не с тем каталогом — сама команда от этого не ломается.

## Настройка

`~/.config/nohands/config.toml`, читается `tomllib` при старте; файла нет —
значения по умолчанию:

```toml
[shell.llm]
backend = "ollama"          # "ollama" | "none"
model   = "qwen2.5-coder:3b"
url     = "http://localhost:11434"
```

Бэкенд ollama — `POST /api/generate` (`stream: false`) через `urllib`, без
новых зависимостей. Интерфейс `Llm.complete(prompt) -> str`, чтобы позже
добавить другой бэкенд (Claude API).

## Установка

`bootstrap.sh`: если `ollama` не найден — сообщить команду установки и
продолжить (без LLM режим работает на правилах). Если найден —
`ollama pull <model>` (модель по умолчанию; конфиг bootstrap не читает).

## Тесты

`test_shell.py`, запускается venv-питоном, без микрофона и сети:
- правила: таблица «фраза → команда» (символы, флаги, программы);
- пути: временный каталог с `Downloads/`, `Projects/nohands/`, `notes.txt`;
  «сиди загрузки» → `cd Downloads`, «кэт ноутс точка тэ икс тэ» →
  `cat notes.txt`, вложенный путь через «слэш»;
- переход к LLM: заглушка `Llm` вызывается только для фраз, у которых первый
  токен не программа; при исключении заглушки возвращается результат правил;
- `terminal_cwd` не падает и возвращает существующий каталог.

## Документация

README: режим в таблице режимов, раздел «Консоль» (фразы, произношение
символов, настройка LLM). Число фраз в README («грамматика из N фраз»)
обновить: `_check_vocab` сверяет его с `COMMANDS` при старте. Новые слова
(«консоль», «хватит») проверяются по словарю vosk там же — список фраз для
проверки дополняется фразами КОНСОЛИ.

Ограничение: имена из нескольких слов находятся только для синонимов XDG
(«рабочий стол»); прочие слова разбираются как отдельные аргументы.

## За рамками

Claude API, автодополнение по истории шелла, автоматическое выполнение,
подтверждение опасных команд (не нужно: без «ввод» ничего не выполняется).
